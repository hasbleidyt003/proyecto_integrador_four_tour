# 1

Sobre nosotros

¿Quiénes somos?

The Four Tour es una empresa de turismo local dedicada a ofrecer experiencias únicas y memorables en Medellín. Acompañamos a turistas nacionales e internacionales por los lugares más representativos de la ciudad, con un servicio integral de guía turística, transporte, comodidad, confianza y seguridad.

Misión

Brindar experiencias turísticas memorables con recorridos guiados, transporte confiable y atención cercana.

Visión

Ser una empresa líder de turismo local en Medellín, reconocida por experiencias auténticas y seguras.

Objetivo

Que los visitantes conozcan los atractivos de la ciudad de forma cómoda, segura y confiable.

Pilares: Seguridad · Confianza · Cultura · Experiencia

# 2

Nuestros servicios

Tres paquetes, un viajero para cada uno

Bronce

Práctico y guiado

  • Transporte con conductor-guía.
  • Recorrido por los puntos de interés.
  • Monitoreo durante el recorrido.
  • Tiempo total recorrido 4 horas.

Plata

Más acompañamiento

  • Transporte con conductor.
  • Guía turístico en cada parada.
  • Monitoreo del servicio.
  • Tiempo total recorrido 7 horas.

Gold

La experiencia más completa

  • Conductor con acompañamiento de seguridad.
  • Guía turístico en cada parada.
  • Monitoreo permanente.
  • Tiempo total recorrido 12 horas.

Todos los paquetes incluyen monitoreo del servicio durante toda la experiencia.

# 3

Destinos turísticos

Lugares representativos

Pueblito Paisa

Cerro Nutibara. Réplica de pueblo antioqueño con mirador de la ciudad. (recorrido aprox. 2 horas).

Grafitour

Comuna 13. Arte urbano, murales y escaleras eléctricas. (recorrido aprox. 3 horas).

Guatapé

Peñón de 220 m con 740 escalones y mirador al embalse. (recorrido aprox. 8 horas).

Octava Maravilla

El Retiro. Parque temático con réplicas de monumentos. (recorrido aprox. 3 horas).

San Félix

Bello. Montaña, parapente y miradores al Valle de Aburrá. (recorrido aprox. 3 horas)

Provenza

El Poblado. Restaurantes, cafés y bares de alta afluencia. (recorrido aprox. 2 horas).

# 6

Lógica de programación

Proceso en Java

Ejemplo sencillo: una clase Reserva que guarda los datos y los muestra en pantalla.

Reserva.java

public class Reserva {
    String cliente;
    String paquete;
    String destino;

    public void mostrar() {
        System.out.println("Cliente: " + cliente);
        System.out.println("Paquete: " + paquete);
        System.out.println("Destino: " + destino);
    }

    public static void main(String[] args) {
        Reserva r = new Reserva();
        r.cliente = "Ana Torres";
        r.paquete = "Gold";
        r.destino = "Guatape";
        r.mostrar();
    }
}
